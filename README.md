# PROJECT BEAT · Avance 01 Base

Versión inicial/prototipo de Project Beat.

## Contenido

- 1 nivel básico funcional: **ACELERADA**
- Gameplay simple de ritmo con 4 carriles
- UI básica tipo prototipo
- Sistema inicial de puntuación
- Pausa simple

## No incluido en esta versión

- Intro cinematográfica
- Menú de modos
- Configuración avanzada
- Hold Notes
- Pantalla de resultados moderna
- Selector complejo de niveles
- Efectos visuales avanzados

## Controles

- `D / F / J / K`: golpear carriles
- `ESC`: pausa
- `R`: reiniciar al terminar

## Objetivo del avance

Este avance representa el inicio del desarrollo del juego, antes de agregar niveles extra, UI moderna, configuración, resultados avanzados y nuevas mecánicas.

## Rama sugerida

`avance-01-base`
