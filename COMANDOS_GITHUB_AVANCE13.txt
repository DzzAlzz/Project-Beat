COMANDOS PARA SUBIR ESTE AVANCE COMO BRANCH

Abrir Git Bash dentro de la carpeta del proyecto y ejecutar:

git init
git checkout -b avance-13-vfx
git remote add origin https://github.com/DzzAlzz/Project-Beat.git
git add .
git commit -m "Avance 13 - detalles visuales pro"
git push origin avance-13-vfx

IMPORTANTE:
No usar git push origin main --force para los avances.
