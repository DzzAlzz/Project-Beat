DESCRIPCIÓN
──────────────────────────────────────────
Este avance representa una etapa intermedia del desarrollo de Project Beat,
donde el juego mantiene una estructura simple, pero comienza a mejorar la
presentación visual de sus menús y la navegación con teclado.

CONTENIDO DEL AVANCE 09
──────────────────────────────────────────
✔ 2 niveles funcionales
✔ Beatmap del Nivel 1 corregido
✔ Nivel 2 funcional
✔ Sistema básico de offset/calibración
✔ Scoring más justo
✔ Partículas y feedback básico
✔ Menú de pausa más ordenado
✔ Selector de niveles más limpio
✔ Mejor contraste y legibilidad
✔ Navegación con teclado mejorada

CONTROLES
──────────────────────────────────────────
D / F / J / K  → golpear carriles
ESC            → pausa / volver
Flechas / W/S  → navegar menú
A/D            → cambiar nivel en selector
Enter/Espacio  → confirmar
F2 / F3        → ajustar offset
F4             → resetear offset

NO INCLUYE TODAVÍA
──────────────────────────────────────────
✘ Intro cinematográfica
✘ Configuración avanzada
✘ Hold Notes
✘ Sliders reales
✘ Selector de modos
✘ Pantalla de resultados moderna
✘ Niveles 3 a 7
✘ UI final avanzada

OBJETIVO DEL AVANCE
──────────────────────────────────────────
Mostrar una primera mejora visual del juego sin transformar todavía el proyecto
en su versión final. Este avance sirve como evidencia de evolución entre la
versión técnica con offset y las futuras mejoras de interfaz.
