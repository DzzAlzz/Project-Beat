PROJECT BEAT - AVANCE 38
Configuracion Responsive Layout

Este avance corrige la distribucion visual de la pantalla de Configuracion fullscreen.

Se mejoro:
- Escalado de textos.
- Centrado del contenido.
- Alineacion de sliders.
- Alineacion de valores.
- Margenes internos.
- Separacion entre secciones.
- Legibilidad general.

No se agregaron nuevas funciones gameplay.
No se modifico LevelManager.
