PROJECT BEAT - AVANCE 36
Display and Layout Overhaul

Este avance corrige la distribucion visual del menu Configuracion y agrega opciones de pantalla/resolucion.

Nuevas opciones:
- Resolucion: 1280x720, 1366x768, 1600x900, 1920x1080, 2560x1440.
- Modo Pantalla: Pantalla Completa, Ventana, Ventana Sin Bordes.

Mejoras UI:
- Panel de configuracion mas alto.
- Separacion visual entre secciones.
- Sliders mejor posicionados.
- Valores alineados a la derecha.
- Textos alineados a la izquierda.
- Menu mas limpio y profesional.

No modifica gameplay ni sistemas internos de ritmo.
