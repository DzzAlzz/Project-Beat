avance-15-intro-menu

DESCRIPCIÓN
──────────────────────────────────────────
Este avance representa la etapa donde Project Beat incorpora un flujo inicial más completo:
Intro → Menú Principal → Arcade → Selector → Gameplay.

NOVEDADES AVANCE 15
──────────────────────────────────────────
• Se mantienen los 3 niveles anteriores.
• Pantalla de introducción simple al abrir el juego.
• Texto/logo PROJECT BEAT.
• Fade in / fade out básico.
• Menú principal con selección de modo.
• Modo ARCADE conectado al selector de niveles actual.
• Segundo modo visual como PRÓXIMAMENTE.
• Navegación con teclado.
• Offset básico, scoring, partículas y pulido visual funcionando.

NO INCLUYE AÚN
──────────────────────────────────────────
• Configuración avanzada.
• Hold Notes.
• Sliders reales.
• Resultados modernos finales.
• Niveles 4 a 7.
• UI final demasiado cargada.

NIVELES
──────────────────────────────────────────
Nivel 1: ACELERADA
Nivel 2: RITMO FUNK
Nivel 3: SUMMER VACATION

CONTROLES
──────────────────────────────────────────
D / F / J / K  → Golpear carriles
ESC            → Pausa / volver
ENTER          → Confirmar
W / S          → Navegar
F2 / F3        → Ajustar offset
F4             → Resetear offset
