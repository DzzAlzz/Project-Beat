Avance 02 - nivel 2 corregido

DESCRIPCIÓN
──────────────────────────────────────────
Esta versión representa una segunda etapa temprana del desarrollo de Project Beat.
Parte desde una base simple y agrega un segundo nivel funcional, mejoras iniciales
de sincronización, navegación básica entre niveles y pequeños ajustes de gameplay.

NOVEDADES AVANCE 02
──────────────────────────────────────────
  SISTEMA DE NIVELES
    • Nivel 1: ACELERADA
    • Nivel 2: RITMO FUNK 2
    • Navegación básica entre niveles
    • Estructura preparada para seguir agregando contenido

  GAMEPLAY
    • Beatmap del segundo nivel integrado
    • Mejor sincronización básica de notas
    • Sistema de golpes funcional
    • Scoring/combo en estado inicial

  UI
    • Interfaz simple tipo prototipo
    • Información básica de canción y puntuación
    • Menús todavía simples, sin diseño final

NO INCLUYE TODAVÍA
──────────────────────────────────────────
  • Intro cinematográfica
  • Menú de modos
  • Configuración avanzada
  • Hold Notes
  • Sliders reales
  • Pantalla de resultados moderna
  • Efectos visuales avanzados
  • Niveles 3 al 7
