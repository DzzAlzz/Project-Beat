AVANCE 87 – AMPLIACIÓN DEL SISTEMA DE LOGROS Y EASTER EGGS SECRETOS

Base usada:
- Avance 86 corregido.

Archivos modificados:
- Assets/Scripts/Runtime/ProfileAchievementStorage.cs
- Assets/Scripts/Runtime/StartupFlowController.cs
- Assets/Scripts/Runtime/GameController.cs
- Assets/Scripts/Runtime/AchievementNotification.cs

Archivos agregados:
- Assets/Scripts/Runtime/AchievementIconFactory.cs
- Assets/Scripts/Runtime/EasterEggSecretCodeController.cs

Mejoras implementadas:
- Se ampliaron los logros del sistema, manteniendo los logros originales.
- Se agregaron logros nuevos por niveles completados, combos, precisión, rangos y progreso general.
- Se agregaron logros secretos por palabras escritas con teclado.
- Se mantiene el guardado de logros por perfil usando PlayerPrefs + JSON.
- Los logros secretos aparecen ocultos como LOGRO SECRETO / ??? hasta desbloquearse.
- Cada logro usa un ícono representativo mediante AchievementIconFactory.
- La notificación lateral usa el ícono correspondiente al logro desbloqueado.
- La detección de palabras secretas no se ejecuta durante gameplay para no interferir con D/F/J/K.

Funcionamiento de palabras secretas:
- Se mantiene un buffer interno de teclado.
- No se muestra ningún campo de texto.
- Se normalizan las letras a mayúsculas.
- El buffer se limita para evitar crecimiento innecesario.
- Si detecta una palabra secreta y hay perfil con partida cargada, desbloquea el logro y muestra notificación.

- No se modificó la lógica base de gameplay.
