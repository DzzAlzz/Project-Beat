MENSAJE DE COMMIT SUGERIDO:
  Avance 24 - Nivel 7 Her Name Is

DESCRIPCIÓN
──────────────────────────────────────────
Este avance representa la etapa donde Project Beat incorpora
oficialmente el Nivel 7, manteniendo la configuración en pausa
con sliders reales agregada en el avance anterior.

NOVEDADES DEL AVANCE 24
──────────────────────────────────────────
  NIVEL 7 — HER NAME IS
    • Nueva canción integrada: Her Name Is.mp3
    • Beatmap completo para el Nivel 7
    • Dificultad avanzada, superior a los niveles anteriores
    • Selector actualizado mostrando 7 niveles

  TEMÁTICA VISUAL
    • Fondo rosado pastel claro
    • Telarañas negras como detalle visual
    • Inspiración visual estilo Geometry Dash
    • Ambiente misterioso/elegante
    • Toques suaves en rosa, negro y blanco

  SISTEMAS CONSERVADOS
    • Intro del juego
    • Menú principal / modo Arcade
    • Selector de niveles
    • Pantalla de resultados
    • Scoring
    • Partículas
    • Offset/calibración
    • Configuración en pausa
    • Sliders reales de brillo y volumen general

IMPORTANTE
──────────────────────────────────────────
  • Este avance NO incluye Hold Notes todavía.
  • Este avance mantiene LevelManager.cs intacto.
  • No se agregan sistemas avanzados nuevos aparte del Nivel 7.
  • Es una versión histórica para subir como branch de avance.

CONTROLES
──────────────────────────────────────────
  D / F / J / K  → Golpear carriles
  ESC            → Pausa
  ENTER          → Confirmar
  W / S          → Navegar

  OFFSET:
  F2 / F3 → Ajustar timing
  F4      → Resetear
