PROJECT BEAT - AVANCE 34

Accesibilidad Visual

Este avance agrega opciones para regular la intensidad de efectos visuales y un modo de sensibilidad visual.

Opciones nuevas:
- Intensidad de efectos: Muy Bajo, Bajo, Medio, Alto, Extremo.
- Modo Sensibilidad Visual: ON/OFF.

Afecta:
- Glow de notas.
- Hold Notes.
- Particulas.
- Flash de pantalla.
- Pulsos de fondo.

No afecta:
- BPM.
- Canciones.
- Beatmaps.
- Scoring.
- Combo.
- Offset.
- LevelManager.
