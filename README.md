# Project Beat - Avance 19

## Rama sugerida
`avance-19-nivel6`

## Descripción
Este avance representa la incorporación del **Nivel 6: REQUIEM**, con una temática oscura/cinemática inspirada en niveles tipo boss de Geometry Dash.

## Contenido incluido
- 6 niveles jugables.
- Nivel 6 funcional: **REQUIEM**.
- Tema visual oscuro con colores negro, morado y rojo oscuro.
- Estilo boss level con glow fuerte.
- Selector actualizado mostrando 6 niveles.
- Intro, resultados, scoring, partículas y offset funcionando.

## No incluye todavía
- Configuración avanzada.
- Hold Notes.
- Sliders reales.
- Nivel 7.
- UI final demasiado cargada.

## Comandos para subir a GitHub como branch

```bash
git init
git checkout -b avance-19-nivel6
git remote add origin https://github.com/DzzAlzz/Project-Beat.git
git add .
git commit -m "Avance 19 - nivel 6 Requiem boss level"
git push origin avance-19-nivel6
```

> Importante: no usar `git push origin main --force` para este avance.
