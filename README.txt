DESCRIPCIÓN
──────────────────────────────────────────
Avance histórico del proyecto Project Beat.
Esta etapa continúa desde el Avance 05 y se enfoca en mejorar
el sistema de puntuación para que el jugador pueda obtener rangos
más justos según su desempeño real.

NOVEDADES AVANCE 06
──────────────────────────────────────────
✔ 2 niveles funcionales conservados
✔ Ventanas de timing más justas
✔ PERFECT / GOOD / BAD / MISS funcionando
✔ Combo con multiplicador básico
✔ Rangos más equilibrados para evitar quedar siempre en D
✔ Feedback visual simple compatible con partículas
✔ Corrección de partículas del avance anterior conservada

AJUSTES DE GAMEPLAY
──────────────────────────────────────────
• Perfect: ventana más alcanzable
• Good: margen más amplio
• Bad: penaliza, pero no destruye todo el combo de golpe
• Miss: reinicia combo
• Multiplicador progresivo según combo
