MEJORAS DEL CURSOR
- Se reemplazó el cursor anterior por un diseño más pulido, neón y completo.
- Nuevo cursor con borde brillante, relleno morado/cian y acento musical.
- Se agregó textura hover propia: ProjectBeatCursorHover.png.
- Se aumentó el tamaño del cursor visual UI para que se aprecie mejor en build.
- Se agregó respuesta visual al click con escala, leve desplazamiento y rotación.
- Se mantiene el pulso de click.
- Se conserva fallback al cursor normal del sistema si el cursor personalizado falla.
- El cursor sigue usando un Canvas Overlay con sorting alto para que funcione también en ejecutable.

MEJORAS DEL LOGO / ICONO
- Se reemplazó el icono anterior por un emblema PB más llamativo.
- Nuevo icono con estética morada/cian/magenta, barras de ecualizador y pulso musical.
- Se actualizó ProjectBeatIcon.png.
- Se actualizó ProjectBeatIcon.ico con múltiples tamaños.
- Se agregó ProjectBeatLogo.png para usos futuros dentro del proyecto.

IMPORTANTE PARA EL EJECUTABLE
- Para ver el icono nuevo en ProjectBeat.exe hay que generar un build nuevo desde Unity.
- Si Windows sigue mostrando el icono antiguo, puede ser caché de iconos de Windows; crear un nuevo acceso directo o reiniciar el explorador puede actualizarlo.
